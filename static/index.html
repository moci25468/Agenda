设置

外观

开启「自动切换」后，外观跟随系统设置，系统变深色它也跟着变；此时手动拨动上面的「深色模式」会自动退出自动切换，改为手动指定。设置保存在本机浏览器，刷新后依然生效。

账号安全

注销会永久删除该账号的课表快照、手动调整、考试、推送记录以及数据源 配置，无法恢复。若是管理员注销，管理员权限会自动交给最早注册的其他账号。

同步

同步时间由服务器按注册人数自动错峰分配，无需手动设置；想立即更新课表可随时点顶部的「同步」。

每日安排推送

每天到点推送一次明天的安排（需先开启 Bark 或群机器人）。内容可自由组合，全部关闭则不推送。

天气与复习提醒

天气来自 Open-Meteo（免费、无需 Key），默认青岛黄岛区。连续两节连上的课只在第一节提醒里带天气。

按考试名称给出复习建议，同一场考试只提醒一次；早上 8 点后推送。

推送通道

在 iOS App Store 安装 Bark，复制 App 里的 Key 填入即可。开启课前提醒后，每节课、日程、考试开始前都会推送一次。

企业微信 / 钉钉群机器人

在企业微信客户端打开群聊 → 右上角「…」→ 群机器人 → 添加机器人，复制形如 https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=… 的地址粘贴到这里；也可以只填 key（36 位带横线）。钉钉群机器人同理。管理后台 work.weixin.qq.com 的网页地址不能用作推送地址。

最近推送

测试、课前提醒与每日推送的最近结果，失败会写明原因。

课表数据来源

两套数据源各有取舍：门户能反映老师临时调课后的课表，但没有教师字段；正方教务是排课数据的源头，带任课教师和考试安排。默认以门户为准，需要看教务原始排课时可在这里切到正方；考试始终从正方获取。

邀请码

          
新用户凭邀请码注册。生成时可指定「可用次数」：填 1 就是一次性码，填 N 就是同一个码最多能被 N 个人用来注册。有效期 7 天。「自定义邀请码」留空则随机生成；自己填可用中文、字母、数字、_、-，4–32 个字，不能有空格标点或表情（全角数字会自动转半角）。太短太简单的码容易被猜，公开传播建议 8 个字以上。
