用量概览

          

        


        

          
用户管理

          
管理所有注册用户：启用/停用、调整角色、重置密码、编辑信息、删除。停用后该用户无法登录。

          

            
            
            
            
            
          

          

        


        

          
数据源总览

          
查看每个用户当前课表来源（门户 / 正方）与最后同步时间。

          

        


        

          
邀请码

          
新用户凭邀请码注册。生成时可指定「可用次数」：填 1 就是一次性码，填 N 就是同一个码最多能被 N 个人用来注册。有效期 7 天。「自定义邀请码」留空则随机生成；自己填可用中文、字母、数字、_、-，4–32 个字，不能有空格标点或表情（全角数字会自动转半角）。太短太简单的码容易被猜，公开传播建议 8 个字以上。

          

            
            
            
            
            
          

          

        


        

          

            
审计日志

            
          

          
管理员的关键操作记录（停用/删除/改角色/重置密码/编辑信息/邀请码）。默认只显示最近几条，可展开查看完整记录。

            配置，无法恢复。若是管理员注销，管理员权限会自动交给最早注册的其他账号。

每日安排推送

          

            
          

          

            
            
            
          

          

            每天到点推送一次明天的安排（需先开启 Bark 或群机器人）。内容可自由组合，全部关闭则不推送。
          

          
天气与复习提醒

          

            
          

          

            
            
            
          

          

            天气来自 Open-Meteo（免费、无需 Key），默认青岛黄岛区。连续两节连上的课只在第一节提醒里带天气。
          

          

            
          

          
          

            按考试名称给出复习建议，同一场考试只提醒一次；早上 8 点后推送。
          

        


        

          
推送通道

          

            
            
          

          

            
            
          

          
          

            在 iOS App Store 安装 Bark，复制 App 里的 Key 填入即可。开启课前提醒后，每节课、日程、考试开始前都会推送一次。
          

          

            
          

          
企业微信 / 钉钉群机器人

          

            
          

          
          

            在企业微信客户端打开群聊 → 右上角「…」→ 群机器人 → 添加机器人，复制形如
            https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=…
            的地址粘贴到这里；也可以只填 key（36 位带横线）。钉钉群机器人同理。管理后台
            work.weixin.qq.com 的网页地址不能用作推送地址。
