门户接入向导（第一次接入先看这里）
1. 浏览器登录融合门户，进入课表 / 日程页（portal.qut.edu.cn 下的页面）。
2. F12 → Network → 筛选 Fetch/XHR，刷新页面，点开返回课程数据的那个请求（Response 是 JSON，不是 HTML）。
3. 右键该请求 → Copy → Copy as cURL，粘到下面「导入并试拉取」。要复制的是数据请求，不是 sso.qut.edu.cn/sso/login 登录页地址。
4. 若导入后课程数为 0，切到该请求的 Response 全选复制 JSON，粘到「离线分析响应」看字段结构。
安全：cURL 里含登录 Cookie，只粘到本地这个页面，不要发到聊天或群聊；可以把不含 Cookie 的响应预览发给助手帮忙配字段映射。
注意：如果接口地址里写死了周次 / 日期参数，每天同步会一直拿到同一周的数据，导入结果会给出提示。
登录页二维码将显示在下方面板，用微信扫码即可自动获取课表；无需把密码交给程序
