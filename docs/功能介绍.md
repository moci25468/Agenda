# Agenda 知序 · 功能介绍

欢迎使用 **Agenda 知序**——青岛理工大学校园日程助手。它把你的课表、考试、个人日程、空教室和手机提醒集中到一个地方，还能像聊天一样问 AI「明天有什么课」「帮我找间没课的教室」。

本文只介绍**有什么功能**，操作步骤见 `docs/Agenda使用说明.md`。

---

## 一、总览：你能用它做什么

- 自动同步整学期课表，按周查看，临时调课自动更新
- 考试安排、个人日程统一在一个「日程」页管理
- 一键查空教室，也能让 AI 帮你查「我没课的时候哪有空」
- 课表变更、课前、考试、每日安排自动推送到手机（iOS / 安卓）
- 课表与考试一键订阅进手机日历，调课自动同步
- 跟 AI 助手对话：问课表、加日程、查空教室、推送到手机
- 多端可用：电脑浏览器、手机浏览器添加到主屏幕（像 App 一样用）

---

## 二、课表与考试

- **双数据源**：融合门户（推荐，含临时调课，支持扫码登录）＋ 正方教务（学号密码，额外提供考试与空教室）。门户优先、正方兜底。
- **按周查看**：周课表可连续翻周，点周次标题回到本周。
- **手动改课**：添加 / 修改 / 隐藏课程，叠加在同步结果之上，不会被下次同步覆盖，可一键恢复。
- **考试安排**：并入「日程」页，显示科目、时间、考场、座位号、校区，带「N 天后考试」倒计时，考前自动复习提醒。
- **空教室查询**：走正方教务实时查询，按日期 / 节次 / 校区 / 教学楼 / 座位数筛选，记住上次条件。
  - 「查我没课的时候」一键按课表算好的空闲节次查询，默认避开有课的节次；
  - 结果按教学楼折叠展开，AI 查询按节次分组、可直接切换查看。

---

## 三、个人日程

- 在「日程」页的「本周日程」卡片查看与管理；周课表里**没课的空格子**可点「加日程」，自动带上那天和节次时间。
- 「今日」页只保留今日 / 明日安排，干净不重复。

---

## 四、手机推送提醒

- **通道**：Bark（iOS）／ 企业微信、钉钉群机器人（安卓）。
- **提醒类型**：课表变更（调课 / 换教室 / 新增 / 取消）、课前 N 分钟提醒、考试复习提醒、每日安排推送。
- **上课天气**：课前提醒附带当堂天气（免费接口，无需 Key）。
- **智能去重**：同一事项按天去重，不会反复打扰。
- **每日推送可定制**：推送时间与内容可选（明日课表 / 日程与考试 / 天气自由组合）。
- **故障提醒**：门户 Cookie 或正方登录失效时，主动推送提醒你重新登录。
- **可验证**：每个通道都有独立测试按钮，设置页「最近推送」列出每次结果与失败原因。

---

## 五、日历订阅与导出

- **一键订阅**：课表 + 考试同步到手机日历（iOS / 安卓），调课、换教室、加考试自动同步。
- **上课天气**：订阅后每节课描述里附带最近两天的上课天气，出门前看一眼就知道带不带伞。
- **导出兜底**：支持导出 `.ics` 文件手动导入。

---

## 六、AI 助手

- **模型**：OpenAI 兼容接口（通义千问 / DeepSeek / Ollama 等）。
- **懂你的上下文**：自动注入你的课表、考试、个人日程、天气与长期记忆，回答更贴身。
- **对话式操作**（回复末尾的动作标记，前端解析成卡片 / 按钮）：
  - `[添加日程]` 直接帮你把安排写进日程；
  - `[记住]` 记住你的偏好，变成长期记忆；
  - `[查空教室]` 直接查；空教室追问（换小教室、我没课时段等）会沿用上一次查询的日期与节次，不会莫名切回今天；
  - `[推送]` 配置并开启 Bark / 企业微信后，可直接让 AI 把提醒或内容发到手机，结果显示在回复下方；
  - `[追问]` 顺手帮你接着问下一个问题。
- **聊天体验**：输入框上方有快捷按钮；长对话只渲染最近 30 条、向上按需加载历史；刷新可恢复。
- **使用辅导**：没配好推送、日历订阅等时，AI 会一步步教你配置。

---

## 七、搜索

- 顶部搜索框跨 **课程 / 日程 / 考试** 全文检索，320ms 防抖、结果按周分组。
- 点搜索结果可一键跳到对应的周并高亮，找「两周后的某场考试」不用一周周翻。

---

## 八、外观与交互

- **深色模式手动切换**：设置页「外观」卡片可选手动浅色 / 深色 / 跟随系统，刷新保持，并同步状态栏颜色。
- **设置分区导航**：设置页顶部粘性锚点条（账号 · 同步 · 推送 · AI），点锚点滚动到对应分区，滚动时自动高亮当前分区。
- **周课表小屏优化**：编辑 / 导出 / 订阅收进「⋯」更多菜单；支持**左右滑动手势翻周**（已处理与横向滚动的冲突）；日期选择器可跳到任意一周；点周次标题回本周。
- **加载体验**：切换页面、查询空教室、首次加载周课表时有轻量骨架屏 + 顶部细进度条，弱网下不再像卡住。
- **PWA 安装引导**：安卓在支持时弹出一次性安装提示；iOS 给出「分享 → 添加到主屏幕」的指引（一次性，不反复弹）。
- **移动端**：底部标签栏，手机上单手可操作。

---

## 九、多用户与管理员

- 数据按用户完全隔离；首个注册账号为管理员。
- 邀请码注册、用户管理、审计日志；管理员可查看各用户数据源接入状态。

---

## 十、隐私与安全

- 门户 Cookie、正方密码、密码哈希等敏感数据**只存在你部署的服务器本地**，不上传到任何第三方，也不进代码仓库。
- 公网多用户部署务必开启 HTTPS。
- 课表订阅链接带令牌，未登录无法直接读取他人课表。
