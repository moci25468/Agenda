# Agenda 知序

青岛理工大学助手：提供课表查询，考试日期查询，成绩查询，空教室查询，学习通事件通知，通知相关均可使用bark/企业微信bot推送

- **课表**：使用融合门户与正方教务两个数据源，融合门户可提供调课后的数据，正方则是固定课表与考试/成绩/教室查询提供数据，推荐使用融合门户登录，服务器会存储 **浏览器profile**，服务器给给每个用户分配一个更新时间，在更新时若融合门户的cookie过期会自动启动浏览器根据存储的 **profile**自动获取新cookie
- **同步**：服务器会给每个用户设置不用的同步时间，防止同一时间多用户cookie过期获取新cookie时对服务器造成的压力
- **手机推送**：Bark（iOS）/ 企业微信·钉钉群机器人（安卓）；课前 N 分钟提醒、考试复习提醒，均按事项去重不重复打扰；每日安排推送时间与内容可选（明日课表 / 日程与考试 / 天气自由组合）；两个通道各自带测试按钮，可直接验证能否收到；Webhook 填错（例如粘了管理后台网页地址）保存时就会提示正确格式，设置页「最近推送」列出每次结果与失败原因
- **上课天气**：课前提醒附带当堂天气，周课表的课程卡片上直接标出今明两天上课时段的天气 / 温度 / 降水概率（Open-Meteo 免费接口，无需 Key）；接口抖动时先自动重试、再沿用上次成功的数据，不会因为一次网络波动就整块变空，前端在拿到空数据后也会自动重试并每 30 分钟刷新
- **考试安排**：考试并入「日程」页，考前复习提醒（按学科给建议）；考试卡片带「N 天后考试」倒计时数字强调
- **个人日程**：在「日程」页的本周日程查看与管理，点没课时段里的「加日程」可快速安排本周任务；今日页只保留今日/明日安排，不再重复列日程与考试
- **空教室查询**：走正方教务数据，按日期 / 节次 / 校区 / 教学楼 / 座位数筛选；可在「设置 → 课表来源」设置默认校区，查询页会自动带入，使用reids，为获取数据提供更快的速度。
- **手动改课表**：添加 / 修改 / 隐藏课程，叠加在同步结果上不被覆盖，可一键恢复
- **交互与观感**：今日页顶部「下一节课」倒计时直达条；周课表没课的空格子里并列提供「查空教室」与「加日程」，有课的格子不显示；点周次标题可回到本周；深色模式跟随系统，移动端底部标签栏
- **日历**：一键订阅到手机日历(目前仅支持ios日历和google日历)，若不支持订阅会自动导出日历文件。

## 快速开始

```bash
./run.sh          # 默认 8300 端口，首次自动建 venv 装依赖
```

打开 http://127.0.0.1:8300 ，首次启动自动同步演示课表，可直接体验全部界面。macOS 可双击 `start.command` 自动起服务并开浏览器。

## 部署（Docker + nginx）

```bash
docker compose up -d --build
```

Compose 会启动仅供内部网络访问的 Redis 缓存容器，不发布 Redis 端口到宿主机；Redis 内存上限 128 MB，使用 LRU 淘汰策略且不启用持久化。天气缓存 30 分钟、空教室元数据 6 小时、空教室查询结果 60 秒；Redis 不可用时应用降级到进程内缓存或原数据源。单机运行时可不配置 Redis，应用仍可启动并运行。

自定义 Redis 时设置 `REDIS_URL`；可用 `AGENDA_CACHE_PREFIX` 修改缓存命名空间，`REDIS_TIMEOUT` 设置连接/操作超时（秒，最大 2 秒）。

**可选：共享空教室周缓存。** 管理员可通过部署环境变量设置 `AGENDA_ROOMS_SHARED_SEMESTER_START`（`YYYY-MM-DD`）和 `AGENDA_ROOMS_SHARED_COOKIE`（仅使用学校明确允许用于共享空教室数据的独立只读来源）。不要使用普通用户的教务 Cookie，不要提交或记录凭证。未设置时保持原查询行为。

应用启动时异步补齐本周快照，之后每天北京时间 00:30 刷新本周；每校区最多预取 42 个标准两节时段。已登录且学校来源、学期、开学日一致的用户，可直接读取命中的校区快照，不需要个人教务凭证。指定教学楼时，仅在楼号和快照中的楼名能无歧义匹配时从快照筛选；未命中、非标准节次或无法可靠匹配时，沿用个人教务查询。用户可在「设置 → 课表来源 → 空教室查询偏好」保存默认校区与默认教学楼，每次查询仍可临时改选。成功快照保留 8 天，刷新失败不覆盖旧快照，界面显示更新时间。刷新任务按单应用进程运行；多副本部署前需先拆分为单独的刷新任务，避免重复请求。

**可选：按需共享前后各七天的查询。** 仅在学校允许共享、且空教室结果不随教务账号权限变化时，设置 `AGENDA_ROOMS_SHARE_ON_DEMAND=1`。无需管理员 Cookie：首位登录用户用自己的教务来源查询成功后，其他登录用户可复用同一来源、学期、开学日、日期、校区、教学楼和节次的快照。仅允许将北京时间过去第七天至未来第七天（含今天，共 15 天）的查询结果写入共享缓存。新写入结果的有效期固定为七天，查询日期退出写入窗口后，仍可在过期前命中；读取不续期。窗口外未命中时仍使用个人短缓存；不自动预取或刷新，也不把个人短缓存提升为共享。Redis 内存淘汰或重启可提前清除缓存，失效后下次查询重新填充。

数据持久化在 `./data`；进程每天 03:20 自动把数据库与全局配置快照到 `data/backups/`（保留 7 天，权限 600）。

nginx 反代示例：

```nginx
location / {
    proxy_pass http://127.0.0.1:8300;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 120s;   # 一键登录与导入可能较慢
}
```

不用 Docker：`python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`，再用 systemd 跑 uvicorn。

> **安全**：`data/config.json` 含门户 Cookie、`data/campus.db` 含密码哈希，均已 gitignore，切勿提交。公网多用户务必配置 HTTPS。

## 接入真实课表

- **门户（推荐）**：「设置 → 课表来源」→「一键扫码登录」，微信扫二维码自动获取，不接触账号密码。扫码不可用时可用 cURL 导入兜底。
- **正方教务**：「设置 → 课表来源」填学号密码，点「保存并测试登录」验证。学年按教务的「2026-2027」选择、学期选秋季/春季；密码框留空表示沿用已保存的密码。所选学期教务里还没排课时，保存会自动切到教务当前学期，不会把配置改坏。

> cURL 含登录 Cookie，只粘到本地设置页，不要发到聊天或群聊。换学期请重新登录一次。

## 核心链路验证

`python3 verify.py` 覆盖课表与成绩、考试、空教室、天气、推送去重、多用户隔离、邀请码、注销等核心链路。脚本使用临时数据目录并禁用 Redis，不读取生产 `data/`；写入与临时服务用例只在显式运行脚本时执行。
