# Agenda 知序

青岛理工大学校园日程助手：**定时同步课表与考试 → 变更检测 → 手机推送 → 个人日程 / 空教室 / AI 问答**。支持多用户与管理员后台。

> 版本号由 git tag 动态管理，发布用 `./release.sh -m "中文改动说明"`（自动 +1、打 tag、推送）。

## 功能一览

- **课表双源**：融合门户（推荐，含临时调课，支持一键扫码登录）+ 正方教务（学号密码，额外提供考试与空教室），门户优先、正方兜底
- **定时同步**：默认每天 12:00 拉取全量课表并 diff（新增 / 取消 / 调整）
- **手机推送**：Bark（iOS）/ 企业微信·钉钉群机器人（安卓）；课表变更、课前 N 分钟提醒、考试复习提醒，均按事项去重不重复打扰；每日安排推送时间与内容可选（明日课表 / 日程与考试 / 天气自由组合）；门户 Cookie 或正方登录失效时主动推送提醒
- **PWA 安装**：添加到主屏幕后独立窗口全屏启动，像原生 App 一样使用
- **上课天气**：课前提醒附带当堂天气（Open-Meteo 免费接口，无需 Key）
- **考试安排**：考试并入课表页，考前复习提醒（按学科给建议）；未考完的考试一直列在今日页的日程里，考完自动移除
- **空教室查询**：走正方教务实时查询，按日期 / 节次 / 校区 / 教学楼筛选；可在「课表来源」设置默认校区，查询页与 AI 问答都会自动带入；AI 查询结果按第 1–2 节、第 3–4 节…分组，可直接切换节次查看
- **个人日程**：和今日合并在一页，手动添加一次性安排，考试未考完前也常驻列表
- **手动改课表**：添加 / 修改 / 隐藏课程，叠加在同步结果上不被覆盖，可一键恢复
- **AI 助手**：OpenAI 兼容接口（通义千问 / DeepSeek / Ollama），自动注入课表、考试、日程、天气与长期记忆，可对话添加日程、记住偏好、查空教室，并辅导你配置推送、订阅日历等；空教室追问（换小教室、我没课时段等）会沿用上一次查询的日期与节次，不会莫名切回今天；「我没课的时候」由后端按课表算好空闲节次注入上下文，不靠模型自己数课表
- **日历导出**：一键订阅到手机日历（iOS / 安卓，调课自动同步）+ 导出 .ics 兜底
- **多用户与管理员**：数据完全隔离，首个注册账号为管理员，邀请码注册、用户管理、审计日志

## 快速开始

```bash
./run.sh          # 默认 8300 端口，首次自动建 venv 装依赖
```

打开 http://127.0.0.1:8300 ，首次启动自动同步演示课表，可直接体验全部界面。macOS 可双击 `start.command` 自动起服务并开浏览器。

## 部署（Docker + nginx）

```bash
docker compose up -d --build
```

数据持久化在 `./data`。nginx 反代示例：

```nginx
location / {
    proxy_pass http://127.0.0.1:8300;
    proxy_set_header Host $host;
    proxy_read_timeout 120s;   # AI 回答可能较慢
}
```

不用 Docker：`python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`，再用 systemd 跑 uvicorn。

> **安全**：`data/config.json` 含门户 Cookie、`data/campus.db` 含密码哈希，均已 gitignore，切勿提交。公网多用户务必配置 HTTPS。

## 接入真实课表

- **门户（推荐）**：「课表来源」→「一键扫码登录」，微信扫二维码自动获取，不接触账号密码。扫码不可用时可用 cURL 导入兜底。
- **正方教务**：「课表来源」填学号密码，点「保存并测试登录」验证。

> cURL 含登录 Cookie，只粘到本地设置页，不要发到聊天或群聊。换学期请重新登录一次。

## 版本与发布

- 版本号唯一来源是 git tag，运行时由 `app/version.py` 读取；`GET /api/health` 返回版本信息
- 发布：`./release.sh -m "本次改了什么"`（补丁号 +1，可传 `minor` / `major`）

## 验证

`.venv/bin/python verify.py` —— 使用独立临时数据目录，不碰你的真实数据。覆盖课表 diff、考试、空教室协议、AI 上下文与流式、推送去重、多用户隔离、邀请码、注销等核心链路。

## 目录结构

```
app/               后端（FastAPI + APScheduler + SQLite）
  providers/       数据源：mock / portal / zhengfang
  browser_login.py 一键扫码登录
static/            单文件前端
data/              运行时生成（已 gitignore）
verify.py          核心链路验证脚本
release.sh         发布脚本
```
